# Personal Portfolio Website

A sleek, responsive, and modern personal portfolio website built using HTML5 and CSS3. Designed to highlight projects, technical skill sets, and background details in a clean layout with dark and light aesthetic sections.

## 🚀 Live Demo

Check out the live website: http://127.0.0.1:5500/index.html

---

## ✨ Features

* **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports.
* **Hero Section:** Dark-themed introduction with quick action buttons ("Hire Me" / "View Work").
* **About Me:** Showcase of personal background, degree focus, and key highlights.
* **Skills Grid:** Interactive card layout highlighting frontend, backend, and design expertise.
* **Projects Showcase:** Display cards for featured full-stack and web design work with project links.
* **Contact Area:** Clean contact prompt for potential project collaborations or inquiries.

---

## 🛠️ Built With

* **HTML5** – Structured semantic layout
* **CSS3** – Custom styling, Flexbox, CSS Grid, and responsive media queries
* **Font Awesome** – Vector icons for UI elements and skills
